Depends on if we are running a: colony, manor, or a combination of both.

## Options (Can have more than one):
- 100% isolated, only get new settlers from reproduction.
- If a manor, hire new serfs from near-by settlements (manors, villages, cities, etc.)
- If a colony, acquire new colonists via a infrequently occurring ship (means we need ocean/lake/river with a port for it to dock)
## Historic Colonial Manors:
- **Patroonships** in Dutch New Amsterdam (huge manor estates along Hudson River)
- **Maryland's Manor System** - Lord Baltimore granted massive manorial estates to colonists
- **Virginia's Plantation Manors** - functioned very much like English manors but in colonial America
- **Seigneuries** in New France (Quebec) - French feudal manors in the colonies
